## __0.2.0__

### __✨ New__
**- Auto-update system**
#### Check for updates and download them automatically.
#### Powered by Sparkle 2.x (macOS) and WinSparkle (Windows) with EdDSA signing.
#### Available updates show as a badge on the tray icon.

**- Renamer redesign**
#### Complete UI overhaul inspired by Windows PowerRename.
#### Vertical split layout with token-based patterns ($name, $ext, $date), visual case buttons, per-item checkboxes, and persistent undo history with Ctrl+Z.

### __💎 Improvements__
#### PySide upgrade for future compatibility
#### Improved license framework
