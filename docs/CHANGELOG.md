## __0.2.0__

### __✨ New__
#### Redesigned Renamer with PowerRename-inspired UI
#### Vertical split layout with collapsible sections
#### Token buttons for quick pattern insertion ($name, $date, $n, etc.)
#### Per-item checkboxes to exclude files from rename
#### Visual case buttons [Aa] [aa] [AA] [Aa Aa]
#### Wildcard support in search/replace
#### Token support in replace field
#### Undo support for rename operations (Ctrl+Z)
#### Session-based and persistent history
#### Store up to 20 operations for recovery after restart
#### Auto-Update system via Sparkle (macOS) and WinSparkle (Windows)
#### Check for Updates from tray menu and Help menu
#### Automatic background update checks

### __💎 Improvements__
#### Enhanced license security framework
#### Preserve extension case in renamer
