v0.2.0 February 10, 2026

✨ New

  • Auto-update system — Check for updates and download them automatically. Powered by Sparkle 2.x (macOS) and WinSparkle (Windows) with EdDSA signing. Available updates show as a badge on the tray icon.
  • Renamer redesign — Complete UI overhaul inspired by Windows PowerRename. Vertical split layout with token-based patterns ($name, $ext, $date), visual case buttons, per-item checkboxes, and persistent undo history with Ctrl+Z.
  • Right-Click-Menu — Rename & Delete Sequences/Files

💎 Improvements

  • ESC to Abort — Abort all sequence and file searches
  • Drag and Drop — Folder-drag from outside to change rootfolder. Moving/Copying files and sequences out of FSeq
  • PySide upgrade — For future compatibility
  • License framework — Improved
  • Undo for rename and delete (guided Trash restore)
